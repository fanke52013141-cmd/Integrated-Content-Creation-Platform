Design a desktop application screen for a Chinese local-first Windows writing tool called 心流. ALL UI labels in Simplified Chinese. This is the 文章创作 (Article Writing) workspace — the most important screen of the app.

PRODUCT CONTEXT
A marketing-team writer drafts one long-form article here. The article is NOT plain markdown: every factual claim must be traceable to source material. So the right rail carries evidence and review state, not just "AI suggestions". Three work modes exist: 编辑 (write, source view), 预览 (rendered preview), 源码 (raw markdown).

ROLE
- Left rail = CONTEXT: which topic, which account persona, which framework outline, which source materials feed this draft. Read-only reference, compact.
- Center = THE CANVAS: the actual writing surface. This must dominate visually — roughly 55-60% of content width.
- Right rail = EVIDENCE & ACTIONS: AI rewrite actions, citation verification, review opinions, version history.

THREE-COLUMN LAYOUT
Left rail 260px:
- Header: 本次上下文
- Section 主题: 深圳南山教师招聘考经验帖 (with a small "更换" text link)
- Section 账号: 未绑定账号 + hint "本次不套用账号语气"
- Section 框架 (outline, 4 items with checkbox-like state, current one highlighted): 一、报考动机与岗位匹配 / 二、笔试与面试流程拆解 / 三、面试三轮真题复盘 / 四、待遇与避坑提醒
- Section 资料基线: 3 chips — 深圳市N考公告.pdf / 历年真题.docx / 岗位表.xlsx, plus a muted line "本次预计入模 12,400 字"

Center (dominant):
- A compact sticky toolbar: mode segmented control 编辑 / 预览 / 源码, then text-format buttons (标题 加粗 列表 引用 链接 图片), then a right-aligned save state text "已保存 · 15:42"
- Title input: large, 20px semibold, placeholder-free, filled with "深圳南山教师招聘考经验帖"
- Meta line under title: 第 4 版 · 草稿 · 1,240 字 · 预计阅读 4 分钟
- Body: an actual long Chinese article excerpt, at least 5 real paragraphs of plausible 考编 content about 教师招聘流程. Use real paragraph text, NOT lorem ipsum. Add a small superscript-style citation marker [1] after one factual sentence, and a subtle left-border blockquote midway.
- Bottom of canvas: a subtle hairline then a small ghost button 专注写作 (focus writing mode, hides both rails)

Right rail 300px:
- Header: AI 动作
- A compact 2x2 grid of small outline buttons: 改写选段 / 扩写 / 缩写 / 换个说法
- Section 依据核验: 3 rows, each = a claim snippet + status. "深圳市2024年招聘612人" → ✓ 已核实 公告P3. "面试三轮为结构化+试讲" → ✓ 已核实 真题.docx. "待遇约8.5k" → ⚠ 未核实 无来源匹配
- Section 评审意见: 2 opinion cards, each with left color bar + severity + author. "开头缺少个人视角" 中·李编辑, "第二段数据需标注来源年份" 高·王主编
- Section 版本历史: 4 rows, current one highlighted, "v4 当前 · 15:42", "v3 · 昨天 19:10", "v2 · 昨天 11:03", "v1 · 前天"

SIDEBAR (fixed 200px, leftmost)
EXACTLY 3 collapsible groups:
- 创作 (expanded): all 9 stages as a compact vertical list with small step numbers: 账号定位 / 热点洞察 / 选题生成 / 内容框架 / 文章创作 (ACTIVE) / 内容评审 / 智能配图 / 文章排版 / 发布管理
- 资源 (collapsed): 素材库, 提示词
- 系统 (collapsed): 数据与备份, AI 服务
No top progress stepper. The sidebar IS the navigation.

COLOR DISCIPLINE — STRICT
ONE brand blue #0062c4 at varying lightness is the ONLY decorative hue. Use it for links, the active nav item, focus rings, the current version highlight, and the active mode segment. Primary buttons are near-black #1d1d1f.
Saturated color ONLY for semantics: green #047857 = verified/success, amber #b25000 = warning/unverified, red #c5221a = error/severe. No purple, no pink, no orange, no rainbow. NO gradients, NO glassmorphism, NO emoji, NO illustrations, NO colored icons beyond the semantic ones.
Nav active state = light blue tinted background + 2px left accent bar. Do NOT give each of the 9 stages a different color.

VISUAL SPEC
Canvas #f5f5f7. Rails and center surface #ffffff with hairline border #e8e8ed and very subtle shadow. Radius 8px buttons/inputs, 12px cards, max 16px. Spacing 4/8/12/16/20/24/32. Chinese system font (PingFang SC / Microsoft YaHei). Body 14px, meta 12-13px, section headers 13px semibold uppercase-ish tracking, page title 20px semibold. 1.5px stroke line icons 16px, Lucide style. All text WCAG AA (4.5:1 min).

Desktop 1600x1000. The three columns must feel like one integrated workbench, not three separate panels — use subtle shared dividers and consistent 20px internal padding.
