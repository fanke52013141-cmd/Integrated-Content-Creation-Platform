# 热点洞察 · 紧凑密度版

在保持现有信息架构（信号源栏 192px + 中间热榜 + 右侧洞察栏 228px）的前提下，把头部区域压缩到最低：

## 头部（关键）
- 页面标题「热点雷达」从 26px 降到 20px semibold，与统计信息、操作按钮合并为**单行工具条**（约 52px 高）：
  - 左侧：标题 + 内联 12px 灰色统计（显示 45/45 个平台 · 45 个已加载 · 0 条已收藏），统计紧跟标题右侧，不换行不独立成行；
  - 右侧：智能筛选 / 平台设置 / 微博登录·未配置 / 刷新全部 四个按钮，高度 32px、13px 字号。
- 三个视图标签（实时热榜 / 收藏夹 / 筛选结果）紧贴工具条下方 8px，做成分段控件（segmented），高度 36px，选中项蓝字白底蓝描边或浅蓝底。
- 页面顶部留白 16px，块间距 12px。

## 结果
- 三栏内容区起点尽量靠上，占满剩余视口高度；
- 榜单行高收紧（约 44px），字号 13px，热量数字右对齐；
- 保持浅色极简体系：#f7f8fa 画布、白色面板、#17212f 正文、蓝色 #2563eb 仅用于选中标签、墨色主按钮；无渐变、无玻璃效果。
