## 2. 发现的问题与处理

### 2.1 下拉长副标题撑破选项（真实缺陷）

证据：

- 排版主题下拉容器约 190px
- 最长选项内容达到约 438px
- 长副标题设置为 `flex-shrink: 0`，无法收缩

修复：

- 标题优先占用可用空间并省略
- 副提示允许按 46% 宽度收缩、单行省略
- 完整标题与副提示通过悬停 `title` 查看
- 小于 560px 的窗口隐藏非必要副提示
- 保留现有边框、行高、选中态和 `z-index: 1300`

复测：最长选项内容被限制在约 182px 容器内，不再溢出。

涉及文件：

- `src/renderer/src/components/Select.tsx`
- `src/renderer/src/styles/base.css`

### 2.2 主题画廊横向出视口（真实可用性问题）

原实现使用单列横向长滚动，后面的主题卡片会落到视口之外。虽然可以横向滚动，但选择主题不直观。

修复：

- 改为 `repeat(auto-fit, minmax(168px, 1fr))` 自适应网格
- 宽屏多列、窄屏自然降列
- 不再依赖横向滚动寻找后面的主题

复测：三种分辨率下均不再出现卡片越出视口的告警。

涉及文件：

- `src/renderer/src/styles/layout-workspace.css`

### 2.3 重复或多余说明文字（信息密度问题）

处理：

- 九张主题卡片不再重复展示同一段 `FEATURE / 让标题层级更清晰 / 引用、强调与留白`
- 改为纯视觉排版预览，卡片只保留主题名称和必要描述
- 主题画廊操作说明精简为“点击应用”
- 导入弹窗模板说明精简为“标准表格已带表头与示例”
- 排版类型推荐只保留推荐理由，组件建议移入悬停提示

涉及文件：

- `src/renderer/src/components/layout/ThemeGallery.tsx`
- `src/renderer/src/components/ImportDialog.tsx`
- `src/renderer/src/pages/LayoutsPage.tsx`

## 3. 弹窗遮挡审查结论

第一轮记录中的一部分“重叠”来自弹窗正常覆盖背景，并非控件互相遮挡。第二轮已排除 `[inert]` 背景后重新测量。

结论：

- 未发现业务弹窗越出视口
- 未发现首启、快捷键、账号菜单、版本对比或删除确认弹窗越界
- 未发现下拉浮层被弹窗层级遮挡
- 未发现页面级横向文档溢出
