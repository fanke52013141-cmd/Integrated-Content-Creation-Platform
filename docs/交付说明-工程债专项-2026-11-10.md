# 交付说明：工程债专项（批次 5，2026-11-10）

> 上游方案：[优化方案-全量待办与分期计划-2026-11-09](优化方案-全量待办与分期计划-2026-11-09.md) 批次 5。
> 目标：迁移机制版本化、database.ts 巨石开拆、查询热点修复、静态检查门禁、CI 冒烟扩容。

## 范围

**5a. 版本化迁移框架（`src/main/db/migrations.ts` 新文件）**
- 现状整条幂等管线（全量 DDL + ensureAddedColumns 补列清单 + 6 个 ad-hoc 数据搬迁）收敛为 **baseline v3**：任何旧库打开后落版本号 3，行为与旧机制完全一致（零迁移行为变化，5 个新单测验证哨兵库/全新库/未来库）。
- 此后 schema 演进一律走 `MIGRATIONS` 有序 step（version 4+），每步只执行一次、逐个落版本号；改列/重建表从此有正规通道。
- 「更高版本库拒绝打开」守卫由硬编码 `> 2` 改为 `latestVersion()`（database.ts 两处 + canRestoreBackup）。
- **第一个接入点预留**：热点自定义标签（`hot_favorite_tags` CHECK 约束重建）排在框架落地后的第一个 v4 step。

**5b. database.ts 拆分先例（3102 → 3054 行，先例域：素材）**
- 新建 `src/main/repositories/material-repository.ts`：usage/addFile/list/addSearch/addManual/remove/get 七个方法整体搬出（含行映射与「素材被哪些文章引用」反查）。
- `AppDatabase` 保留同名门面方法委托，**调用点零改动**（服务/IPC/渲染层全部不动）；523 个测试全绿验证纯机械等价。
- 剩余域（topics/frameworks/articles/reviews/visuals/layouts/hotspots/providers/prompts）按同模式渐进拆出，每次一个域一个提交。

**5c. 查询热点修复**
- `listPublications`：逐行 3 次快照查询（3N+1）改批量 Map 预载，并加 LIMIT 300 防全表膨胀。
- `listMaterials`：加 LIMIT 500 底线（素材行无大字段，完整分页列为后续演进）。
- `AccountLayoutPanel`：`articles.list()`（全量 JOIN 含 raw_markdown）改 `listSummaries({ accountId, limit: 200 })`——摘要接口现成支持账号过滤，预览下拉改用 title 字段。

**5d. 静态检查门禁（方案改道：ESLint → tsc 严格选项）**
- 原定引入 typescript-eslint；实测与项目的 **TypeScript 7.0.2**（native preview）硬冲突（peer 要求 <6.1），强行 legacy-peer-deps 风险大于收益。改用零依赖等效方案：
  - `tsconfig.node.json` / `tsconfig.web.json` 开启 **noUnusedLocals + noUnusedParameters**（strict 之外的两大主力门禁）。
  - 清理全部存量违例：约 20 处未用 import/变量/类型（article-layout-service、ipc.ts、mock-bridge、ProvidersPage/LayoutsPage/MaterialsPage/AccountPage/VisualStudio/Layout/WorkContext、6 个测试文件），顺带删除 3 处死代码（MaterialRow/mapMaterial 残留、SearchServiceRow、bundleName）。
- typecheck 现在拦截：未用变量、未用参数、类型缺失——ESLint 的核心价值点已被 strict+双开关覆盖。

**CI 扩容（`.github/workflows/verify.yml`）**
- 新增 `smokes` matrix job：materials / reviews / topics / frameworks / layouts / hotspots 六个冒烟分片并行（fail-fast 关闭，单分片超时 30 分钟）。
- 原有 verify job 保持：单测全量 + build + workflow/publishing 冒烟。
- 分批选择依据：这六个冒烟在本机全绿且覆盖批次 2~4 全部改动面；visual-studio / account-layouts / workspace / visual 等重 Electron 冒烟继续留在本地 `test:smokes`（CI 上 13 个 Electron 串行启动过重）。

- 迁移框架 5 个新单测（tests/db-migrations.test.ts）：全新库落 baseline、哨兵库收敛、step 只跑一次、未来库拒绝、applyPendingMigrations 幂等。

## 已知边界

- database.ts 仍 ~3050 行：拆分是渐进路线，本批只交付先例域+迁移框架，剩余域每域一提交（收益递减，topics/frameworks 域方法量最大可优先）。
- ESLint 缺位由 tsc 双开关补位；pre-commit 钩子未加（无 lint script 可挂，typecheck+test 已是提交习惯，待 lint 工具链可用后再挂）。
