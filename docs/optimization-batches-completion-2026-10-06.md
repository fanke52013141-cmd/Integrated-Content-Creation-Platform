## 交付结果与启动

四个批次的核心功能均已实现，并通过源码构建、单元测试、完整桌面回归与打包程序验证。

- 启动入口：项目根目录 `启动优化版.cmd`。

## A：核心可靠性

### 配置验证与保存

增加“测试并保存”的原子操作：测试当前表单，通过后保存同一份配置与验证结果。测试期间禁用配置切换和编辑，避免测试参数与最终保存参数不一致。保存后的内部表单加载不再触发“放弃未保存修改”确认。

连接参数变动使验证失效，名称修改不会误清除验证；保存使用版本时间戳防止旧窗口覆盖新配置。验证记录绑定连接修订与模型。

### 改稿、重试和候选

改稿明确区分“当前文章新版本”和“独立备选稿”。当前文章模式固定生成一个版本；多候选独立保存。请求持久化原始正文、指令、模式、资料片段及引用，失败后仅补生成未成功的候选，不读取后来变动的表单。

原文章或本地工作草稿在生成期间变化时，结果安全另存为备选稿，提示作者比较后采纳。比较弹窗同时绑定原文章和候选版本，过期比较不能覆盖正文。正式采纳才产生原文章新版本。

### 未完成结果恢复

正常结束、长度截断、过滤拒绝、缺少结束标记、空内容分开处理。截断或状态不明的结果保留内容，不被当作正式成稿写入文章；可以人工检查另存或要求续写完整备选稿。部分流式内容定期落盘，重启将仍在运行的任务标为中断，包括早于最近 50 条的记录。

任务与候选初始记录、正式成稿与来源及结果状态分别在事务中写入，避免保存中途失败留下半套数据。

主要文件：`article-generator.ts`、`content-completion.ts`、`workflow-repository.ts`、`CreationHistory.tsx`、`ProvidersPage.tsx`。

## B：创作与交付闭环

### 无 AI 配图

新增手动图片集合，允许没有模型的本地图导入。正文工具栏可以直接导入并插入图片，发布页可以直接导入封面；导入后立即更新可选图片列表。未在正文指定光标位置时默认追加文末，避免图片意外插到标题之前。

导入校验 PNG/JPG 文件内容和大小，随机文件名避免碰撞，数据库保存失败清理新文件。旧配图表在事务中迁移，保留方案、图片 ID 和引用，原模型生成方案回填为 generated。

### 复制与公众号图片

排版页提供两个明确动作：

1. “复制图文（带格式）”：使用公众号上传接口准备正文图片，按目标 AppID 复用上传缓存，复制结果不包含应用内部图片协议；准备结束再次核对文章版本。
2. “复制正文，手动插图”：将图片替换为编号占位，离线可用，提示在后台补插图片。

复制和推送复用图片准备逻辑；准备图片或推送期间不能修改公众号连接，避免图上传到错误账号。独立 HTML 导出继续内嵌图片。

### 查询与旧稿定位

文章列表由数据库统一筛选正文、标题、账号和状态，计数与分页一致。过期异步响应不会覆盖最新查询，查询期间不展示旧条件的列表。

评审、配图、排版等页面使用分页搜索选择器，并按 ID 单独读取当前文章；当前作品不受最近 30 条或历史 500 条边界限制。摘要列表不再传完整正文和所有版本，同名作品显示版本、时间和短 ID。

### 不确定推送

unknown 状态增加人工核对入口：确认已收到、确认未收到、仍无法确认。必须记录核对说明，可填写远端草稿 ID；保留核对结论与时间。已收到归档为草稿，未收到归档为明确失败后才允许重试，仍无法确认继续保留 unknown。

重试使用冻结交付快照，新记录关联原记录，不自动重复推送不确定结果。

主要文件：`wechat-publish-service.ts`、`LocalImageImport.tsx`、`ArticlePicker.tsx`、`useSelectedArticle.ts`、`PublishingPage.tsx`、`LayoutsPage.tsx`。

## C：写作效率与输入交接

文章编辑默认源码单栏，新增明确的预览、源码、编辑与预览三种模式。专注写作隐藏侧栏、流程条、新稿表单和文章列表，可随时退出；工具栏保持可见，并提供标题、加粗、列表、引用、链接等基础格式动作。

保留本地暂存和正式保存的区别，展示暂存中、暂存失败、待保存版本等状态，版本历史和对比继续可用。窄窗口与 100%、125%、150% 缩放下验证键盘到达及保存。

通用选题不再强制先创建或锁定账号。热点交接显示来源、时间、链接，并明确收藏快照不代表实时核验；框架和文章生成前可查看本次主题、账号、框架章节和资料基线，素材选择跨页面保留。

生成进度展示实际完成数量和运行时长，不使用虚构百分比或剩余时间预测。

主要文件：`ArticlesPage.tsx`、`TopicsPage.tsx`、`FrameworksPage.tsx`、`useGenerationStream.ts`、`pages.css`。

## D：依据与数据保障

### 长素材和上下文

TXT、Markdown、PDF、DOCX 的解析全文单独保存，列表摘要仅用于预览。超过限制明确拒绝，不再静默保存前两万字；旧素材已经丢失的尾部不能补造，需要重新导入。

全文支持分段查看与搜索。PDF/DOCX 在有时间与内存限制的 Worker 中解析，减少对主进程的阻塞。备份包含完整文本，但不保留上传前的原始二进制文件。

生成按主题相关性选择来源片段，并保留素材 ID、文档版本、原文位置、出处和实际片段。界面展示预计使用范围与未入模字数；实际使用片段冻结在生成快照和版本依据中。预算考虑模型上下文、输出上限、基础提示及余量；当前采用保守字符估算，尚未接入模型专属 tokenizer 或向量检索。

### 证据评审与采纳

评审区分事实意见与表达意见，显示原文锚点、出处及摘录。来源 ID 必须存在于提供给模型的片段，依据摘录必须逐字匹配，原文锚点也要匹配原稿；不满足时明确为未核实。即使来源匹配，也只代表找到了资料，不代表事实已由系统独立证实。

意见默认未采纳。作者勾选后先生成独立改稿候选，再通过对比正式采纳；只有正式采纳才把评审任务标为已应用。

### 可携带备份与复盘

新增用户选择外部目录导出、选择外部备份包导入。先在内部制作去凭据数据库，再写入外部暂存包，完成后改为最终目录；不会先把含密钥的数据库复制到外部。

包记录格式与 schema 版本、数据库及图片校验值。导入先校验版本、完整性、图片名称和校验值，再放入受控恢复区；确认摘要后恢复。拒绝未来 schema 和损坏包，恢复失败回滚数据库与图片。升级已有数据库前保存恢复副本。

发布复盘增加统计截止时间、阅读、分享、净增关注、转化数等可选手动指标。未填保持空值，0 保持真实的零；经验仍由作者明确保存到账号记忆。

主要文件：`material-context.ts`、`MaterialDocument.tsx`、`MaterialContextPreview.tsx`、`review-service.ts`、`workspace-service.ts`、`DataPage.tsx`。

## 验收边界与后续事项

1. 公众号上传与推送回归使用模拟服务，未连接真实公众号，也未执行真实发布。真实公众号后台粘贴后的样式和微信最终预览需要使用有权限的账号验收，不能以模拟测试代替。
2. 新目录恢复已在本机隔离环境验证；未进行第二台物理电脑验收。外部备份去除了机器绑定凭据，设计上恢复后需要重新配置密钥。
3. DOCX Worker 在源码和打包程序均已验证；PDF 解析仍需补充多版本、复杂版式及异常文档样本验收。
4. 计划中备份列表的丰富摘要、容量预警、保留策略与提醒尚未实现；当前已有包校验、导入摘要与安全恢复。生成历史界面显示最近 20 条、仓库读取最近 50 条，尚未提供历史记录分页管理。
5. 当前窗口保留多处流程导航，专注模式可收起；整站导航进一步压缩和完整首次使用向导属于后续界面迭代。片段检索目前为关键词排序，界面的上下文范围为预估，实际依据以冻结快照为准。
6. 磁盘写满、系统断电和安装程序交互全过程未实机验证。测试覆盖了事务异常、损坏包以及版本拒绝，不声称覆盖所有操作系统故障。

以上事项与已实现功能分开列示，避免把实现完成等同于所有外部场景已验收。
