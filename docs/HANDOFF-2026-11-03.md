# Handoff：全页面 UI 精简、下拉直显与解耦性审查

交接日期：2026-11-03（Asia/Shanghai）。基于 `d4f6f7c`，改动尚未提交（提交由用户决定）。

## 1. 背景

按用户走查意见做一轮全局优化：页面/弹窗的说明文字过多、下拉菜单过多（"能展示出来就展示出来"）、部分布局溢出与挤压、品牌名"心流内容创作工作室"冗余；同时从"每个环节可独立使用、可第三方导入、可串联"的产品理念审查各模块解耦情况。

## 2. 本轮改动（28 个文件，+151/−204，另有新增 Segmented 组件）

### 全局
- 品牌名精简为「心流」（`Layout.tsx`）。
- 删除约 30 处冗余提示：页面内"请先…""生成后请核对…""即可开始"类说明改为按钮禁用原因（title）+ 点击 toast 兜底；保留错误态、费用与不可逆操作提示。覆盖首页、文章、评审、框架、排版、发布、配图、选题各页及导入/手动选题/新建草稿弹窗。
- 新增 `components/Segmented.tsx` 分段直选控件（复用全站 `.segmented` 样式），固定小选项集不再用下拉：配图（出图质量/分辨率/正文图数量/配图密度/参考方式）、排版（平台/文章类型）、框架（数量）、选题（数量）、文章（每批生成/改稿方式/候选数）、发布（核对结果）。
- `.segmented` 全局改为可换行 + 选项文字单行（窄容器换行而不是文字竖排）；`.content` 增加 `overflow-x: clip` 横向滚动守卫；排版表单网格改 `minmax(0,…)` 防溢出。

### 重点页面
- 文章工作台：右侧「AI 动作/版本历史/事实核对」三个折叠面板改为常开直显（智能改稿、候选数、改稿方式全部可见可点）。
- 配图工作台：移除「快速开始」说明块，「使用推荐设置」收敛为行内按钮；风格弹窗字段重排为两列网格，并新增**自定义字段**（名称+内容，最多 10 个，随风格版本持久化，按顺序并入风格描述与样图提示词）。
- 排版页：「此主题适合…」等提示移除；「设为默认版式」收入固定版式设计工具条；文章类型列加宽，不再竖排。
- 框架页：移除底部「已锁定的框架会直接带进…」引导条（卡片内「写文章→」是唯一下一步）。
- 各页 NextStepBar 文案精简为短语（评审/配图/排版）。

### 解耦性审查结论
各环节入口现状：账号定位（新建/导入/字段可增删）、热点（手动添加/导入/平台登录获取）、选题（AI/手动/导入/导出/字段模板可配）、框架（AI/手动/导入，选题与账号均为可选引用）、文章（AI/粘贴/.md/DOCX/HTML 导入，框架与账号可选）、评审（角色可配、导入评审）、配图（AI 方案+导入方案+本地候选图导入）、排版（AI 渲染+导入 HTML）、发布（导入交付信息）。未发现强制依赖上游的阻塞；本轮把"发布待确认核对结果"等剩余下拉改直显后交互方式已统一。评审/排版空态文案已改为"先准备一篇文章（可写可导入）"以体现第三方导入路径。

### 自动化回归同步
5 个冒烟脚本因控件形态变化同步更新（smoke-publishing/optimization/visual-studio/articles/topics/ui-layout），并为「账号筛选后读列表」等紧时序断言补了确定性等待（waitForFunction）。

### 根因缺陷修复
`Select.tsx` 打开菜单后用 `requestAnimationFrame` 才把焦点移入列表——存在一帧空窗：键盘用户和自动化断言都可能跑在它前面（本轮 ui-layout 回归的「Short listbox receives keyboard focus」即因此偶发失败）。已改为提交后同步聚焦。
