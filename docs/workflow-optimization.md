# 0.2.0 创作流程优化说明

## 本轮实现

| 领域 | 改动 | 用户得到的结果 |
| --- | --- | --- |
| 创作入口 | 保留主题、热点、资料、导入四种入口；账号、热点和评审标注为可选 | 未配置 AI 时也能导入、编辑和排版 |
| 当前作品 | 侧栏、流程导航和作品栏携带文章 ID；切换文章期间隐藏旧编辑器 | 进入下一阶段后仍操作同一篇作品 |
| 工作草稿 | SQLite 持久暂存，区别于已保存版本；修订号与基础版本检查 | 切页、整进程重启及备份恢复可以保留修改 |
| 保存竞态 | 只清除实际提交的内容；保存期间新增输入继续暂存 | 连续 Ctrl+S 和继续输入不会丢字 |
| 版本冲突 | 拒绝覆盖新版本；提供另存新文章；AI 生成期间有变化时保留候选 | 手工修改与 AI 结果都能保留供选择 |
| 编辑体验 | 默认源码编辑、基础格式工具、预览、折叠改稿和历史 | 正文成为编辑页的主要操作区 |
| 下游一致性 | 共用保存提示，主进程独立阻止脏稿进入评审、配图方案、排版和交付 | 下游产物与已保存正文版本一致 |
| 账号选择 | 显式区分继承、不使用、指定账号 | 选择“不使用账号定位”不会偷偷继承框架账号 |
| 失败重试 | 正文失败候选重试保留原生成或改稿请求；任务状态区分全部失败、部分完成和取消 | 重试不会变成另一次不相关的写作请求 |
| 发布表单 | 作者、摘要、封面和原文链接按文章保存；公众号切换清除旧素材选择 | A 文章的封面和摘要不会带到 B 文章 |
| 交付预检 | 校验文章归属、版本、公众号、封面、正文图片及文件完整性，显示目标与正文预览 | 推送之前可以知道哪些项目需要处理 |
| 正文图片 | 本地地址转换为公众号图片 URL；上传映射以资产、AppID、用途隔离 | 公众号正文不会引用仅本机可访问的图片地址 |
| 发布确定性 | 请求之前保存交付快照和待确认记录；明确失败可重试，结果未知必须核对 | 网络中断或崩溃后不会盲目重复推送 |
| 导出 | 文件名含版本或排版标识，不覆盖同名文件；Markdown 复制图片，HTML 内嵌图片 | 离开应用后仍可查看内容与图片 |
| 图片删除 | 正文历史、工作草稿、排版和交付快照引用中的图片禁止删除 | 不会因为清理配图而破坏已保存作品 |
| 备份恢复 | VACUUM 一致性快照覆盖 WAL 数据；数据库和逐图片校验，暂存切换并自动回退 | 恢复失败后保留恢复前数据库和图片 |
| 运行互斥 | 备份恢复拒绝与生成、上传、暂存并发；公众号配置变更与交付互斥 | 不会把操作写进被替换的数据库或上传到错误公众号 |
| 列表性能 | 正文列表按 30 篇分页查询摘要，选中后才读版本历史 | 列表读取不再加载全库历史版本 |
| 工程结构 | 独立工作状态仓库、发布 IPC、图片解析和操作互斥模块；新增 Windows CI | 后续维护和回归更容易定位 |

## 推荐使用流程

1. 从导入或主题进入，按需要配置 AI 服务。
2. 编辑正文，观察“正在暂存 / 已本地暂存 / 暂存失败”状态。
3. 保存为版本，再进入评审、配图或排版。
4. 公众号交付页核对当前文章、正文版本、目标公众号、封面和摘要。
5. 推送成功后到公众号草稿箱正式发布，再登记发布链接与复盘。
6. 定期在“数据与备份”创建完整备份。

## 验证方式

本机验证结果：20 个测试文件、131 项测试通过；12 套完整 Electron 冒烟通过；生产构建与 Windows x64 安装包生成成功。浏览器全页面走查无控制台错误。

- `npm test`：原有回归及新增草稿持久化、保存竞态、版本冲突、WAL 回退、图片校验、导出防覆盖、公众号图片替换、缓存隔离、重试快照、未知结果和互斥检查。
- `npm run build`：主进程、preload、renderer 类型检查及生产构建。
- `npm run test:smokes`：原有各模块 Electron 实际流程与新增整进程重启、跨作品发布表单和备份流程。
- 冒烟测试设置临时 `MOLIU_USER_DATA_DIR`；不连接真实公众号，不使用现有安装中的数据。
- 浏览器走查覆盖全部页面、暗色模式，文章冒烟覆盖 1180px 与 100% / 125% / 150% 缩放下的键盘保存和导出可达性。

## 范围与剩余限制

- 按要求没有实现旧项目迁移工具。新版本备份需包含完整图片校验清单及本轮数据库结构。
- 公众号接口使用本地 mock 做自动验证；真实账号权限、IP 白名单、封面规格与线上内容限制需在实际账号环境验收。
- 微信交付不提供自动正式发布；结果待确认时须到公众号后台核对。
- 文章工作台分页已实现。下游文章选择器当前最多加载 500 篇摘要，超大内容库仍需补充服务端检索选择器。
- 任务结果与状态落库；正文失败重试保留当前页面内的原请求。重启后自动恢复完整请求与自动重试尚未实现。
- 本轮没有全面重写历史数据库模块、建立完整组件库或引入遥测分析；后续应根据实际用户测试继续迭代。
- 安装包只用于分发本轮代码，不会自动安装或替换正在使用的旧应用。
- 直接试用建议双击根目录 `启动优化版.cmd`，启动 `release/win-unpacked/心流.exe`，数据写入独立的 `%LOCALAPPDATA%\心流-optimized-0.2`。真实已安装应用与其数据没有被本轮测试修改。
