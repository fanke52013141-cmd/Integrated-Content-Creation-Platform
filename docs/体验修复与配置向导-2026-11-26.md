# 体验修复与场景式配置向导（2026-11-26）

## 1. 框架深度预研状态可见

框架生成器现在会返回明确的预研状态，不再静默跳过：

- `used`：已使用 X 条公开资料
- `skipped`：未配置搜索模型或没有可用主题
- `disabled`：本次关闭了深度预研
- `empty`：搜索完成但没有可用资料
- `failed`：搜索失败，已跳过并继续生成框架

框架预览区会显示对应提示；预研失败不会阻塞框架生成。

## 2. 框架页自动选中已锁定选题

从侧栏直接进入「内容框架」时：

- 优先选中当前账号关联的已锁定选题
- 如果没有当前账号匹配项，选中任意已锁定选题
- 用户手动选择「不关联选题」后，后续刷新不会强制覆盖

## 3. 账号锁定后的下一步引导

账号保存并锁定后，编辑器会显示：

> 账号定位已锁定，可以开始寻找内容方向
> **下一步：找热点**

点击后直接进入热点洞察。

## 4. 热点 CTA 去重与失败源重试

- 删除收藏后重复出现的「去生成选题」引导条
- 保留收藏栏中的唯一「生成选题」主按钮
- 新增「重试失败平台（N）」按钮，只重试当前失败来源
- 首屏只刷新可见平台，隐藏平台按需刷新
- 全部刷新改为单平台并发调度，避免慢平台阻塞同批次其他平台

性能实测：

- 首屏可见平台：约 **3.6 秒**
- 刷新全部 56 个平台：约 **15.4 秒**
- 此前全量刷新约 **39 秒**

## 5. 排版性能复核与结论

对排版管线做了单独计时：

- `renderPreview`：约 **53 ms**
- `layouts.create`：约 **19 ms**

此前走查记录中的 31–32 秒主要来自 Electron 全页截图采集，不是排版生成本身。排版生成链路当前已处于毫秒级，无需牺牲校验换取速度。

## 6. 场景式配置向导

AI 服务页新增「场景式配置」向导，提供三种场景：

- **只写作**：文本模型
- **写作 + 配图**：文本 + 生图
- **完整创作**：文本 + 搜索 + 生图

向导会：

1. 按场景展示所需模型
2. 自动带入供应商预设、Base URL 与模型标识
3. 逐步收集 API Key
4. 在确认页展示配置摘要与费用提醒
5. 逐个测试连接并加密保存
6. 部分成功时保留已保存结果，修改后可单独重试

即梦 CLI 场景会自动检测本机登录态，无需 Base URL 与 API Key。
