# ADR 0005：热点 AI 筛选模型与草稿边界

- 状态：Accepted
- 日期：2026-07-28
- 对应需求：`PRD-热点模块.md` 4.3

## 决策

- 每次筛选由用户选择具体连接和模型；
- 初始值为可用连接中的默认模型；
- 只允许选择已锁定账号定位；
- 筛选调用绑定账号当前精确版本 ID；
- 单次请求一次性发送所选平台的前 N 名，默认 N=20，硬上限 200 条；
- 输入严格为 `<账号定位>` 与 `<热搜列表>` 两个 XML 数据块；
- 不做关键词过滤，不允许热点文本改变系统指令；
- 模型必须逐条返回契合度、理由和切入角度，缺项、重复序号或格式错误均视为失败；
- 筛选结果只存在于当前界面的草稿态，不直接写入收藏；
- 人工采纳后才调用收藏接口，写入不可变热点源快照并默认打 `待选题` 标签。

## 原因

连接下已经支持多个模型和别名。显式选择可以让用户按速度、质量和上下文能力切换，同时保留默认模型的低操作成本。筛选结果不直接持久化，可避免模型误判污染下游原料池。

## 后果

- 无已锁定账号或无可用模型时禁止筛选；
- AI 结果必须人工复核；
- 可单条采纳、忽略，或批量采纳全部高契合结果；
- 重新筛选会替换当前草稿结果；
- 模型调用仍由统一网关记录延迟、模型与成功状态。
