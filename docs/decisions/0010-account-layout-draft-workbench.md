# ADR 0010：账号版式工作台、持久草稿与并发启用

状态：已实现（2026-10-22）

## 决策

- 在“账号定位 → 公众号版式”提供独立工作台，不要求账号已有关联文章。画像的锁定状态与版式生命周期分别管理。
- 账号与平台各有一份可编辑草稿，保存到 `account_layout_drafts`。保存草稿不产生启用版本，也不改变文章生成时读取的默认绑定。
- 草稿记录 `revision` 和 `baseVersionId`。保存时检查 revision；启用时同时检查草稿 revision 和当前账号绑定。版本写入、绑定更新和草稿基准更新在同一个 SQLite 事务内完成。
- 启用后保留草稿行并递增 revision，将其基准设为刚启用的版本。这样旧窗口不能因 revision 重新从 1 开始而覆盖后续草稿。
- 当前默认版式已被其他窗口更新时，拒绝旧草稿启用，保留编辑内容。用户可明确更新启用基准，再检查并启用。
- 账号工作台和文章排版页复用参数控件、默认配置比较和隔离预览文档。已有高级 CSS 会随账号版式草稿保留；结构化 JSON 包仍不包含高级 CSS 和品牌图片资产。
- 工作台支持标准组件样稿及当前账号的真实文章预览，支持 320/375/430px 近似屏宽。所有预览从 Markdown 和配置在主进程生成，不写正式排版历史。
- 未保存修改在本窗口 sessionStorage 暂存；显式保存草稿才保证跨应用重启保留。离开编辑页签或关闭窗口时对未保存内容提示。

## 交付与验证

- 数据库测试覆盖草稿不生效、账号/平台隔离、重启恢复、并发保存与启用、历史稿保持原 HTML。
- Electron 冒烟覆盖无文章时配置、离页恢复、JSON 包往返、真实文章预览、新稿自动套版、并发冲突后保留参数。
- 本地预览和自动化验证不代表完成真实公众号粘贴、草稿 API 或手机端验收。

## 后续

品牌图像资产、包含图像的版式包及目标公众号首套正式规范继续按实施方案推进。
