# ADR 0006：选题生成的版本与结构化输出约束

- 状态：Accepted
- 日期：2026-07-28
- 对应需求：`PRD-选题AI.md` 4.2–4.7

## 决策

- 选题生成只接受已锁定账号定位，并将精确账号版本作为不可变引用保存；
- 收藏热点以收藏快照 ID 作为软引用，一并保存在选题上；手动主题不要求热点引用；
- 每个批次允许 1–5 个独立模型调用，使用同一个明确选择的连接与模型；单项失败返回失败项，不回滚成功项；
- 全局 schema 是模型 JSON 的唯一字段契约：解析必须精确匹配当前字段集合，不能默默接受额外或缺失字段；
- 编辑选题会创建新版本而非覆盖；锁定、选题库归档和删除是独立状态操作；
- 选题库是平铺的本地收藏，不引入标签系统。

## 原因

选题是后续内容框架的决策输入，既需要保留可追溯的输入版本，也需要允许用户快速修订和选择。严格 schema 使字段设置与 AI 输出保持一致；独立调用把格式错误、超时或单次模型失败隔离在单个草稿内。

## 后果

- schema 变更只影响后续生成，已有选题保留生成时的字段结构；
- 生成结果进入草稿墙，用户确认后再加入选题库；
- 下游读取草稿时可以根据引用状态显示草稿警告；
- 模型调用继续由统一网关记录模型、延迟与结果状态，不保存提示词正文。
