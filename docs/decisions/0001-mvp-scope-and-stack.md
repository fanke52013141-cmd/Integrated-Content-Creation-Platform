# ADR-0001：首期范围与技术栈

- 状态：已接受
- 日期：2026-07-28

## 决策

首期只实现以下纵向切片：

1. Windows 桌面应用工程底座；
2. 模型网关的 OpenAI-compatible 通用适配器；
3. SQLite 本地数据层与 DPAPI 支撑的密钥安全存储；
4. 账号定位 AI 的向导、生成、人工编辑、版本、锁定和回滚。

技术栈采用 Electron、TypeScript、React、SQLite。界面遵循用户提供的“AI味道”设计系统。

## 边界

Claude、Gemini 原生协议和图像生成只保留扩展接口，本期不实现。热点、选题、素材、框架、写作、评审、配图、排版均不进入首期功能实现。

## 原因

先验证密钥安全、模型兼容、结构化输出、本地持久化和版本状态机这些高风险基础能力，再扩展业务模块。
