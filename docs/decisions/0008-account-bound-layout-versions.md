# ADR 0008：公众号版式按账号绑定不可变版本

状态：已决定（2026-10-22）

## 背景

公众号希望跨文章保持统一视觉规则。原 PRD 的“模板不绑定账号”会把一致性留给每次手工选择，容易因漏选或误选而漂移。现有排版稿已保存最终 HTML，因此可以在不重新渲染旧稿的前提下增加账号级版式版本。

## 决策

1. 公众号版式按账号画像和平台绑定；一个账号修改样式时创建新的不可变版本，再将默认绑定指向新版本。
2. 未显式选择单篇覆盖时，排版生成器解析文章关联账号的当前版式。未配置账号版式时，沿用现有默认主题。
3. 每份排版稿保存已生成 HTML、账号版式版本 ID、版式配置快照和渲染器版本。打开、复制和发布历史排版稿不重新渲染。
4. 首批编辑能力以现有内置主题为基础，支持正文字号、行高、段落间距、二级标题字号、强调色和正文色等结构化参数。主题 CSS 是派生产物，不作为唯一配置源。
5. 文章第一个顶层 H1 作为独立标题元数据；微信公众号草稿的正文不重复显示该标题。代码围栏中的 `#` 不作为标题。
6. 微信外链脚注在 Markdown token 层生成，以保留链接内部的加粗、代码等行内格式。
7. 继续使用 ADR 0007 决定的 markdown-it + juice 渲染链。本次参考 doocs/md、WeMD、Markdown Nice 的主题分层与组件工作流；没有复制上游代码或新增第三方依赖。
8. 草稿推送和用户显式点击“上传正文图并复制”时，本地正文图片通过微信[上传图文消息内图片接口](https://developers.weixin.qq.com/doc/offiaccount/Asset_Management/Adding_Permanent_Assets.html)转换为可用于文章正文的图片 URL；按公众号 AppID 和文件摘要缓存。此路径与封面 `media_id` 上传分开。

## 边界

- 当前绑定对象是账号画像和平台，不表示已经支持多个公众号 AppID 授权；发布凭证仍是独立的单通道设置。
- 首批主题参数编辑不是完整的品牌版式编辑器。后续品牌文字组件、样稿和结构化包见 ADR 0009，独立工作台及草稿/启用流程见 ADR 0010；品牌图像资产和更细组件规范继续按实施方案推进。
- 首批正文图片上传只接受 PNG/JPG 且文件小于 1 MB；其他格式或超限图片会在推送前明确报错。真实账号下的图片展示仍需验收。
- 预览结果不等同于公众号后台或手机端实机验证，粘贴和草稿 API 仍需分别验收。

## 后果

- 数据库新增账号版式版本和当前绑定记录；旧排版稿的新增字段为空，继续从已保存 HTML 读取。
- 更新账号版式不修改其他账号或历史排版稿。回退通过载入旧参数并发布新版本实现，保留版本顺序。
- 之后扩展具体公众号身份绑定时，应新增身份级优先级规则，不得把账号画像绑定解释成多授权通道已经完成。
