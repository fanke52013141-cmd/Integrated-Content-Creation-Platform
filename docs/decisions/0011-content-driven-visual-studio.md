# 内容配图工作台

## 决策

在现有配图和图片资产服务之上增加内容规划、风格版本与文章应用流程。入口为“智能配图 → 内容配图工作台”；原有方案、导入和生图功能仍可从“原有方案与图片”访问。

流程：选择已保存文章 → AI 规划图片用途和位置 → 编辑方案 → 选择风格 → 生成／编辑提示词 → 生成样图 → 生成剩余图片 → 采用候选图 → 预览 → 确认应用为文章新版本。

## 数据与一致性

- 风格独立于文章保存，修改生成不可变版本；支持归档、历史参数载入、账号默认绑定。
- 默认绑定指向风格，创建新方案时读取最新可用版本；已有方案和图片项冻结所选风格版本。
- 每个风格包含一张主参考图，存放在本地 images 目录。由已有图片创建风格时复制文件，避免原资产删除影响风格。
- 每个图片项拥有 UUID 和单调增加的槽位，覆盖、删除、排序不会重新编号。正文顶部图在现有资产表中映射为 inline，工作台保留 header 类型。
- 风格／主题／用途／比例发生变化后提示词标记为需更新。人工编辑提示词、锁定提示词、修改图注和位置不会强制重写提示词。
- 所有方案更新使用 revision 比较，异步 AI 结果不能覆盖期间发生的人工修改。
- 未保存方案现已自动暂存到 SQLite，会话缓存作为补充；正式方案仍需显式保存。任务和草稿恢复详见 ADR 0012。
- 生成请求保存方案、图片项、风格快照、提示词、供应商、模型和参考方式。生成任务继续复用现有图片任务续查逻辑，候选图由 pack/kind/slot 对应到图片项。

## 参考图调用

- 图片参考模式读取本地主参考图，调用当前供应商的上传接口取得地址，再调用图片编辑接口；上传或编辑失败直接显示错误。
- 用户可以显式选择仅文字风格模式。系统不会在图片参考失败时自动降级成文字生成。
- AI 提取风格描述使用真正的多模态图片输入，要求供应商启用 vision 能力。
- 风格样图使用统一书桌主题，按文字描述生成；满意后保存为风格参考图。此操作会产生生图费用。
- 参考图的色彩、笔触与质感一致性由实际模型决定；不承诺仅靠普通图片编辑接口就能实现严格的风格解耦。

## 文章交付

- 公号封面独立设置发布表单的 coverAssetId，正文顶部图和正文图进入 Markdown。
- 位置保存文章版本、内容块原文、重复出现序号和插入方向。代码块内空行不拆成独立位置。
- 预览只读；文章变化时重新定位，缺失或歧义位置阻止应用，用户可重新选择位置。
- 应用同时保存文章新版本、封面表单和撤销记录；清空失效的排版选择。
- 同一方案在其应用版本上再次应用时，从原始正文重新放置图片，不累积重复插图。
- 应用后正文有其他修改时，阻止直接重新应用或撤销，避免覆盖用户后续编辑。
- 撤销恢复应用前正文和发布表单，并保留文章版本历史。

## 验证边界

本地自动化验证使用真实 Electron、SQLite、IPC、渲染器及本地模拟模型 HTTP 服务，验证请求与数据行为。真实供应商的生成美感、风格一致性、参考图支持差异及公众号手机端最终效果需要以实际账号和模型实图验证。

多张辅助参考图、跨图人物一致性和复杂信息图自动设计为后续扩展。
