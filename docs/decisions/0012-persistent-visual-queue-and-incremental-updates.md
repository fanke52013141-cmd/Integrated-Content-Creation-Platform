# 配图任务、自动草稿和增量更新

## 行为

- 配图生成队列由主进程执行，任务在 SQLite 中保存，页面只负责提交与观察。单张、批量和失败重试使用同一队列。
- 重启后继续尚未提交的排队任务；已有供应商任务标识的先续查，绝不当作新请求重复提交。
- 网络断开、提交中止或远端结果不明确时，保留“结果待核对”。有任务标识时可点击“再查一次”，没有可用结果并经用户确认后才允许重新生图。
- 任务写入全局台账并广播状态，切页后可以从任务中心回看。风格样图保存独立记录，支持按原任务标识续查与载入恢复后的风格参数。
- 暂停排队任务可以直接继续；暂停已提交任务时，继续操作优先查询原任务。暂停中的提交没有取得远端标识时，按结果未知处理。

## 图片状态

图片签名包含主体、用途、比例、最终提示词、所选风格版本和参考图标识。图注、位置、排序和采用动作不影响签名。

生成完成时保存资产签名，队列恢复结果时同样保存。修改单张图片只让该图提示词失效；仍有效的图片可继续生成。批量入口只提交缺图或旧图位置。

旧候选图继续保留，但显示“需要更新”。如果用户确认沿用旧图，记录针对此刻方案的确认；再次修改内容或风格后，该确认失效。导入图在采用时记录当前签名；早期没有生成参数记录的图片提示人工核对。

## 草稿

编辑后防抖自动暂存到 SQLite，保留会话缓存兜底。草稿版本与正式方案版本分开递增，显式保存正式方案时同时校验两者，避免覆盖另一个窗口的新编辑。

清空草稿使用保留版本号的空记录，防止删除后从零重新计数造成旧客户端误写。旧方案草稿不自动覆盖新方案，而是显示内容对照，允许用户载入后检查。

## 位置与预览

文章段落改变后，先精确匹配已确认位置。找不到时，根据文本双字片段相似度提供最多两个候选，并显示原段落和新段落。相似度是文本匹配分数，不能代替用户判断；不自动接受建议。

图片应用预览、文章编辑器实时预览和正式排版使用同一个渲染器；通过文章所属账号读取默认版式。正式输出冻结版式版本和配置快照。

## 质量与交付

用户可以选择质量和分辨率。普通生成沿用供应商分辨率字段，参考图编辑沿用已适配的像素尺寸接口。供应商不支持时显示错误，不静默降低质量或丢弃参考图。

显示已记录图片费用、估算标志和费用未知数量。单张配置价格只是基础估算，高质量和高分辨率的真实账单以供应商返回为准。

公众号正文图先读取当前文件计算摘要，再按 AppID 与内容摘要复用已上传地址；不依赖本地文件名不变的假设。
