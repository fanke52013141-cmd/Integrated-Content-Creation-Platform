# ADR-0002：允许引用草稿，但必须绑定具体版本

- 状态：已接受
- 日期：2026-07-28

## 决策

下游模块可以消费草稿态账号定位，但创建关联时必须保存：

- `source_id`：账号定位 ID；
- `source_version_id`：被消费的不可变版本 ID；
- `source_status_snapshot`：关联创建时的 `draft` / `locked` 状态。

当状态快照为 `draft` 时，下游界面必须持续显示黄色警告。账号之后产生新版本、锁定或解锁，都不会自动改变既有下游产物使用的版本。

## 删除与失效

版本引用记录不可修改，只能删除并重新创建。账号被删除后，引用记录保留，解析时标记为“来源已失效”，下游产物本身不删除。

## 原因

这既允许用户快速试用草稿，也避免上游内容变化导致旧产物无感漂移。
