## Stitch 对照差异（优化版 vs 现状）——已确认方向性共识

Flow Minimal Studio 设计系统完整采纳了本应用 tokens（墨色主按钮、#2563eb 仅强调、统一遮罩 rgba(15,15,20,0.42)、4/8/12/16/20/24/32 间距、8/12 圆角），以下为 14 屏优化版相对现状的共性处理，与 P1 清单互相印证：

1. **每屏一个墨色主操作**：卡片内的推进按钮降级为次级描边（topics 锁定并生成框架→次级），避免与页面主按钮抢焦点
2. **列表行/卡片操作分组**：编辑类图标聚拢、删除隔离弱化（topics/articles/accounts 一致）
3. **徽章降噪**：多徽章压到一枚状态徽章 + 元信息并入 12px 次级行（accounts）
4. **顶栏/工具条收敛**：6+ 按钮收进「更多 ▾」，状态文字降为页题下一行小字（hotspots）
5. **空态紧凑**：高度减半、图标缩小、一句话+一个动作（materials/reviews/home）
6. **禁用态**：浅底虚化 + 一句原因，不再是大灰实块（hotspots/publishing/reviews）
7. **步骤条**：编号只出现一次（数字徽章），紧凑排列加连接线（publishing/visuals）
8. **宽屏网格化**：宽右栏改两列卡片网格（topics）

（逐屏截图与备注见 `.stitch/audit-2026-11-06/shots/`；屏幕 id 索引见附录）

## 修复方案（四组）

### A. 视觉降噪（styles/*.css）
P0-1~8、P1-1~4、P1-11：token 归一、遮罩/对话框统一、残留清理、helper-text 归一、disabled 样式统一。

### B. 交互便捷（pages + 少量组件）
P0-9~10、P1-5~7、P1-9~10、P1-15~16：同名按钮区分、双编号去重、Pagination 组件、导入合并菜单、layouts 双按钮去一、确认标题具体化、页头命名对齐。

### C. 文案精简
P1-8、P2-1~17：共享常量抽取（缺模型指引、空态句、暂存状态、暂无素材）+ 逐条精简；保留新手必需的关键指引（SavedVersionGate 主体文案、首次使用引导）。

### D. 局部简化
P1-12~14、P1-17~19：topics 图标分组与双列网格、home 横条压缩、materials 空态收紧、accounts 徽章降噪。
