# 标准导入表格与任意环节进入（2026-11-27）

## 可以怎么开始

现在不要求从账号设定开始一路生成。你可以：

- 直接导入账号设定，再去热点、选题或排版
- 直接导入话题 / 写作框架，再写文章
- 直接导入文章，再配图、排版、发布
- 直接导入外部图片和配图方案，再插入正文
- 直接导入排版稿，再进入公众号发布预检

每个导入弹窗都提供 **下载标准模板**。模板带表头与示例行，可直接用 Excel / WPS 编辑。导入内容默认保存为草稿，不覆盖已有文章或配置。

## 各阶段模板

| 环节 | 模板与主要格式 | 导入后的去向 |
|---|---|---|
| 账号设定 | CSV 字段表 | 账号定位草稿 |
| 热点 | CSV | 热点收藏 |
| 话题 / 选题 | CSV | 选题草稿 |
| 写作框架 | CSV，每个章节一行 | 框架草稿，可继续写文章 |
| 文章 | CSV / Markdown / DOCX / HTML / JSON | 文章草稿，可进入配图和排版 |
| 图片 | CSV 图片与配图方案，JSON 仍兼容 | 当前文章的配图方案与图片资产 |
| 评审 | CSV | 当前文章的外部评审意见 |
| 排版稿 | HTML / JSON | 当前文章的排版稿 |
| 发布信息 | CSV / JSON | 当前文章的发布表单 |
| 提示词 | JSON | 已存在提示词的新版本 |

## 表格填写规则

### 账号设定

两列：`字段名称`、`字段内容`。账号名称、目标受众、写作风格最关键，其余字段可留空。

### 话题

一行一个话题，默认字段包括：选题主题、切入角度、目标读者、核心观点、情绪基调、拟标题方向、备注。

### 写作框架

三列：`框架主题`、`章节名称`、`章节内容`。同一个框架主题可以写多行，每行对应一个章节，章节顺序按表格顺序保留。

### 文章

两列：`标题`、`正文`。正文支持换行和 Markdown，例如 `#`、`##`、列表、加粗、引用和图片引用。CSV 使用标准双引号转义，Excel / WPS 保存时会自动处理。

### 图片

字段包括：

- 图片类型：`封面` / `文内图` / `发布图`
- 图片路径或网址：本地图片相对路径，或 `http(s)` 公网地址
- 位置：文内图希望插入的正文段落；工作台无法精确匹配时会要求人工确认
- 用途、比例、提示词、替代文本、封面文案

本地图片必须放在 **CSV 表格同目录或子目录**，不允许绝对路径或 `../` 目录逃逸。单张图片最大 10MB，支持 PNG / JPG / JPEG。

示例目录：

```text
我的配图任务/
  图片-标准导入表.csv
  images/
    cover.png
    inline-1.png
```

表格中填写 `images/cover.png`、`images/inline-1.png` 即可。

导入后图片进入当前文章的配图资源，之后可以插入正文并重新生成排版；不会把图片当成正文文本素材。

## 发布流程验证边界

当前已验证：账号定位 → 热点 → 选题 → 框架 → 文章 → 配图 → 排版 → 公众号草稿推送 → 发布记录与复盘。

微信公众号草稿推送使用模拟网关通过，不能直接等同于线上真实发布。真实使用还需要：

1. 在发布管理中配置公众号 AppID / AppSecret
2. 准备有效的公众号封面素材 ID（thumb_media_id）
3. 确认公众号接口权限和账号主体满足微信要求
4. 在公众号后台完成最终预览与正式发布
