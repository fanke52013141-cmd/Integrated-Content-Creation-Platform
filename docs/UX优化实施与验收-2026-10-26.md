# UX优化实施与验收

本批基于0748627，承接docs/HANDOFF-2026-10-22.md。测试使用独立无界面浏览器和后台Electron，不连接用户日常浏览器，不操作桌面。真实服务仅请求已配置文本服务和用户授权的豆包搜索，不执行公众号推送。交付提交号可用`git log -1 -- docs/UX优化实施与验收-2026-10-26.md`查询。

## 已落实

- 窄内容区（≤760px）文章库改为按需打开的弹窗，正文优先显示。保留搜索、筛选、分页；选中文章后关闭，Escape关闭后焦点回到入口。次要入口收入“更多操作”。
- 生成历史折叠态收紧；框架去除148px旧吸底留白；选题、框架、发布表单、模型配置减少独立卡片滚动，使用页面主滚动。
- 新增可选的ModalBase独立滚动正文布局，应用于文章导入/恢复、版本对比、任务中心、框架编辑、文字素材及评审角色。头尾不参与滚动，正文不能覆盖底部按钮。
- 下拉浮层取消right:0导致的拉伸；按触发器宽度计算，按实际上下空间限制高度，限制左右边界。失效选项显示明确提示。
- 配图文章选择器约束宽度，避免局部溢出。框架章节输入补充一致的高度、边框和留白。
- 页面切换重置主滚动区域，防止进入下一页时标题已被滚出。
- 提示词页简化技术信息，变量与key收进高级详情，历史图标标题同排；新增默认文本模型，与提示词内容一起形成版本。
- 账号、热点筛选、选题、框架、文章生成/改稿、旧配图方案及新配图规划/提示词生成，进入页面时优先带出对应绑定；本次手动选择覆盖默认，不改写提示词绑定。
- 新配图规划和提示词生成纳入中央提示词管理。评审角色可以新建或编辑，并单独选择模型；未指定时继承本次评审模型。
- 提示词模型绑定随SQLite保存和恢复，重启保留；JSON导入导出支持modelBinding:{providerId,modelId}；导入旧格式时保留当前绑定，显式null解除绑定。失效模型不能保存。
- 各类导入提供JSON结构示例及按类型列出的格式；热点兼容sourceUrl/sourceName/summary/snippet/publishedAt，避免搜索结果丢失来源、摘要与日期。
- 新工作台“导入方案”现在写入四阶段方案，保留外部提示词并锁定。正文位置仅精确且唯一匹配时接受，否则标为未确认，应用前需选择；不通过猜测插入。导入写入pack与studio plan在同一事务内。
- 从旧方案入口导入仍保留旧行为；没有批量迁移历史方案。新工作台限定1—12张与现有五种比例；其他比例明确报错并提示旧入口。
- 首次账号引导只在文本服务验证通过后显示就绪；启动bat改用自身目录，移除旧D盘路径。

## 验证

- `npm run build`：类型检查及生产构建通过。
- `npm test -- --maxWorkers=4`：35文件、350项通过（含新闻别名导入、模型绑定版本/重启、外部配图方案等新增回归）。
- `MOLIU_SMOKE_BACKGROUND=1 node scripts/run-all-smokes.mjs`：16套生产Electron回归全部通过，覆盖账号、热点、选题、素材、框架、文章、评审、两代配图、排版、账号版式、发布预检、备份恢复、工作流，以及本批模型绑定与外部配图导入。文章覆盖63篇检索与分页、草稿恢复、版本对比、100%/125%/150%缩放下键盘保存；优化套件覆盖500篇以外旧文和无模型本地图片接入。
- `npm run test:ui-layout`：独立无界面Edge；14个页面×1440/1180/960三种尺寸，文章库焦点恢复、长章节滚动、文章导入/素材/框架/版本对比/任务中心/角色弹窗、提示词绑定预选及手动覆盖、下拉边界、切页滚动复位通过。
- 14路由×3尺寸扫描未出现整页横向溢出，原配图选择器局部溢出候选已消失；自动图标扫描包含隐藏元素和顶部对齐误报，不能当作全部图标已逐个验收。
- 截图在`artifacts/ui-layout-optimized/`；页面数据是明确的开发样本，不作为真实业务结果。

## 使用方式

提示词→选择环节→默认文本模型→保存为新版本。模型绑定只提供进入生成页面时的默认值，实际请求仍携带页面中显示的模型。本次临时改模型不会改提示词配置。文章写作与改稿分别选择。

评审→评审角色→管理角色选择已有角色或新建→选择角色模型→保存。

智能配图→内容配图工作台→先选文章→导入方案→JSON预览并导入。导入后检查所有图片用途、比例及正文位置，再生成/导入候选图并预览应用；导入本身不调用模型或写回文章。

## 范围限制

真实服务联调：豆包搜索返回5条新闻，标题和来源齐全，其中一条成功接入素材库。文本服务使用本机已有微信云开发AI配置进行真实连接测试，HTTP 429返回`user access to this plan has been disabled`，属于上游套餐停用，故真实账号/选题/文章生成未通过验收。没有用模拟输出代替真实联调。可恢复套餐或配置另一项可用文本服务后运行`npm run test:live-configured`复测；脚本只读原库中的服务配置，在隔离目录使用加密凭据及Local State，结束后清理该目录，不改原库。

按用户要求跳过真实生图、公众号草稿API和推送；手机显示未验证。浏览器视觉回归采用演示桥，生产Electron的流程回归采用真实IPC和隔离数据库、模拟外部响应，不能据此宣称真实生图与推送已经通过。

后台Electron复现：PowerShell中设置`$env:MOLIU_SMOKE_BACKGROUND='1'`后运行`npm run test:smokes`。源码测试使用offscreen并禁止show/focus，打包应用不启用此开关。新增import-bindings套件验证生产IPC、模型绑定版本恢复与界面默认选中、外部方案提示词锁定及未知位置、重新加载持久化。文章回归更新旧入口选择器，并等待目标锁定稿实际出现，避免上一轮搜索结果造成误判。

未统一重写全系统保存语义：文章工作草稿、正式版本、账号版式显式草稿各自保留原语义。本批不迁移历史配图方案，不自动配置密钥，不改变真实公众号状态。

新增表prompt_model_bindings关联提示词版本，保存模型ID，不保存密钥；首次启动自动建表。回退源码不会自动回退数据，升级/回退前沿用应用已有备份流程。
