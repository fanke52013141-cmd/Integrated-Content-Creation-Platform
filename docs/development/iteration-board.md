## 后续优化池（按价值排序）

1. **本地素材真实 API**：验证 `uploadimg`、thumb、draft update 和读回；这是当前最大未覆盖项。
2. **真实移动设备/Dark Mode**：形成主题截图与问题清单。
3. **文档导入**：DOCX、授权网页、历史 Markdown，统一进入文档模型。
4. **数学与图表**：MathJax/Mermaid/PlantUML 的真实浏览器与降级矩阵。
5. **品牌资产**：Logo、默认封面、署名、禁用词和品牌色板。
6. **团队协作**：评论、审核、冲突检测、权限与审计；实时光标后置。
7. **高级组件**：只增加能被自动验证的参数化组件，不先追求数量。
8. **多平台**：复用统一文档模型和素材层，逐平台增加适配器。
9. **数据反馈**：任务成功率、人工修改率、同步耗时与阅读数据反哺。

## 永久质量约束

- 任意新主题或组件必须带测试文章和读回结果。
- 任意新增 CSS 必须先过规则检查，不能仅凭浏览器截图。
- 任意同步重试必须验证幂等，不允许重复创建素材或草稿。
- 任意不支持效果必须自动降级或阻断，不允许静默消失。
- 任何“完成”都不得把 mock 当成真实公众号结果。
