## 5. 明确未实测及生产边界

以下是外部条件，不再用“已完成”掩盖：

1. **本地素材真实 API 尚未验证**：没有使用 AppSecret 调用 `uploadimg`、thumb 或真实 `draft/add/update`。这些适配器已完成并通过 HTTP 形状和 mock 契约测试，但生产账号验收仍需凭证。
2. **没有物理 iOS/Android 设备实测**：当前有真实 Chromium、手机宽度截图、官方 Dark Mode 规则和微信编辑器实测，没有宣称完成真机 Dark Mode 全量验证。
3. **WordPress、Webhook、知乎、掘金、CSDN、头条没有执行真实发布**：前两者有真实适配器及测试，后四者为明确 mock；UI/API 会显示模式，不显示成真实发布。
4. **生产认证与密钥托管未启用**：当前是单工作区 POC。团队工作区为内存实现，actorId 需要由外部可信认证提供；生产需要 OAuth/第三方平台授权、KMS 和租户隔离。
5. **跨进程协同不是多人实时光标**：已有乐观锁、版本和审计，没有实时合并、多人会签或防篡改 WORM 审计存储。
6. **长文与复杂视觉仍需持续预算控制**：2 万字符是硬限制；自定义字体、复杂 SVG 和部分现代 CSS 仍需按版本做回归，不能承诺未来所有 WebView 都绝对一致。
