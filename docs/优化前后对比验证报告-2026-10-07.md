# 优化前后对比验证报告（2026-10-07）

## 结论

对 2026-10-06 ~ 10-07 落地的优化（三项数据/逻辑修复 + 热点榜单序号与视觉修复），用**同一套自动化场景**在「优化前构建」「优化后构建」「0.1.0 安装版」三个版本上做了 A/B 对比。**四项优化全部验证生效，且无任何回归**：前后测试套件全绿（247 → 269），三种构建运行期间渲染层零报错。

## 验证方法

- **优化前基准**：commit `c8ba8ed`（三项修复落地前的最后一个提交）在独立 worktree 构建而成；已校验产物标记（无 `discardGenerationTask`、含「选题方向」字段），确保对比的确实是修复前代码。
- **优化后版本**：`release/win-unpacked-new/心流.exe`（基于最新提交 `d43021b` 打包，与 `release/心流-0.2.0-setup.exe` 同源）。
- **0.1.0 安装版**：用户机器上实际安装的 `D:\Program Files (x86)\心流\心流.exe`，用于热点榜单 UI 的「修复前」实证。
- 三次运行使用**同一个场景脚本**（`verify-ab.mjs`）：各自以隔离的临时数据目录启动、连同一个本地模型网关（响应内容固定），依次执行「账号 AI 生成→锁定、自定义位置备份→列表→恢复、正文→配图方案→故意触发配置错误、热点榜暗色模式截图与计算样式采集」。
- 数据目录隔离 + 临时目录校验，未触碰真实安装版数据与用户运行中的实例。

## 量化对比结果

### ① 账号定位字段（修复：默认字段对齐 PRD 八字段）

| 指标 | 优化前 (c8ba8ed) | 优化后 (d43021b) |
|---|---|---|
| AI 生成后字段数 | 9 | **8** |
| 含「选题方向」字段 | 是（**永远为空**——提示词只要求 8 字段） | 否 |
| AI 实际填充字段 | 8 / 9 | **8 / 8** |
| 账号完整度 | **89** | **100** |

**体现**：修复前账号定位存在一个永远无法被 AI 填充的死字段，完整度上限被压到 89%；修复后字段清单与提示词契约一致，完整度可达 100%，用户不再面对一个“看起来该填但 AI 永远不填”的空字段。

### ② 自定义位置备份（修复：备份列表与写入位置一致）

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 备份写入 userData 自定义子目录后，出现在备份列表 | **否**（列表 0 条） | **是**（列表 1 条） |
| 该备份可否从界面入口恢复 | 不可见即不可恢复 | **可以**（恢复成功） |

**体现**：修复前用自定义位置创建的备份在「数据与备份」页凭空消失、无法恢复；修复后写入位置与列表位置一致，备份创建即可见、可恢复。

### ③ 任务台账对配置错误的处理（修复：配置类失败不落台账）

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 故意触发“生图能力未开启”后的台账 failed 记录 | **1 条**（`visuals:该供应商未启用图片生成能力…`） | **0 条** |
| 台账总行数 | 3（含 1 条假失败） | 2（全部为真实执行过的任务） |
| 用户仍能收到明确的配置缺失提示 | 是 | **是**（错误提示原样返回） |

**体现**：修复前“缺配置”会以“生成任务失败”的名义留在任务台账，污染任务中心并推高首页「需要处理」计数；修复后台账只记录真实跑过的任务，同时全局错误提示保留，用户仍能立刻知道缺什么配置。

### ④ 热点榜单序号渲染（修复：`<ol>` 补挂 `hot-item-list` 类）

| 指标 | 0.1.0 安装版（用户在用） | 优化前构建 (c8ba8ed) | 优化后 (d43021b) |
|---|---|---|---|
| 榜单 `list-style-type` | **decimal（原生序号，重复展示根源）** | none | none |
| 屏幕表现 | 「**1.** <span>**1**</span> 刚刚，ChatGPT…」双重序号 | 单序号 | 单序号 |
| 前三名配色 | 红/橙/紫（红 rgb(255,69,58)） | 红 rgb(255,69,58) | **主色蓝 rgb(10,132,255) 浅底徽标** |
| 热度值 | 粘在标题尾部（“提速 50%39”） | 独立成列 | 独立成列、右对齐 |
| 行结构 | 间距失衡、无边框分隔 | 有分隔 | 等高行 + 细分隔线 |

**体现**：用户截图的重复序号在安装版上完整复现并被消除；新版前三名徽标收敛为主色单色相（不与语义色冲突），行布局与热度值排版也一并改善。

说明：原生序号是 CSS `::marker` 伪元素，不存在于 DOM 文本中，因此以计算样式 `list-style-type` 为权威判据（安装版 = decimal，新版 = none），截图为直观佐证。
