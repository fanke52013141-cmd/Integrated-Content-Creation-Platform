## 4. 接手与复现

```powershell
npm.cmd install
npm.cmd run build
npm.cmd test
npm.cmd run test:ui-layout
$env:MOLIU_SMOKE_BACKGROUND='1'
node scripts/run-all-smokes.mjs
```

不要在桌面回归运行期间重新执行构建：页面按需加载的资源哈希会被替换，导致测试访问不存在的旧文件。退出后台模式可执行 `Remove-Item Env:MOLIU_SMOKE_BACKGROUND`。

| 脚本 | 用途与产物 |
| --- | --- |
| `scripts/goal-audit.mjs` | 先构建；真实 Electron，独立临时工作区；14 页空态／种子数据、关键详情、窄窗口截图，输出 `artifacts/goal-review/`。首启引导单独截图后关闭；没有主题切换入口时跳过暗色截图 |
| `scripts/capture-interaction-audit.mjs` | Edge 无头浏览器＋Vite 5177；逐个打开匹配的页面级菜单和非破坏性弹窗，输出 `artifacts/interaction-audit/manifest.json`，逐条查看其中的 `error`。不自动覆盖嵌套弹窗和所有状态 |
| `scripts/smoke-ui-layout.mjs` | Edge 无头浏览器＋Vite 5176；14 路由×1440×900、1180×720、960×640，附焦点、滚动、菜单和关键弹窗检查；输出 `artifacts/ui-layout-optimized/` |
| `scripts/smoke-visual-studio.mjs` | 配图完整流程及菜单证据，输出 `artifacts/visual-audit/`；红色候选图为模拟生图返回的测试素材 |
| `scripts/smoke-account-layouts.mjs` | 账号版式参数、预览内容／设备切换、窄窗口和版式版本流程；菜单截图位于 `artifacts/layout-audit/` |
| `scripts/smoke-workspace.mjs` | 导入映射、创作跳转、事实线索及备份检查／恢复，部分截图位于 `artifacts/backup-audit/` |
| `scripts/smoke-publishing.mjs` | 模拟公众号接口及断线后的待确认状态，输出 `artifacts/publishing-audit/` |

浏览器脚本需要已安装 Microsoft Edge；布局脚本也支持用 `MOLIU_BROWSER_EXECUTABLE` 指定浏览器可执行文件。端口 5176、5177 需空闲。`ux-audit-browser.mjs` 是构建产物的补充空态取证脚本，不替代真实 Electron 回归。

## 5. 未完成项与建议接续顺序

1. **先补状态清单，再逐项截图。** 按“入口 → 弹窗 → 菜单 → 保存／取消 → 异常”列举实际分支，对照已有 manifest 和脚本；已做导入映射、版式菜单、备份及发布待确认的部分状态，不应再笼统记为全部未检查。
2. **优先复核本批公共控件影响面。** 超过 12 项时的搜索、无匹配选项、长选项／已删除选项、向上展开后搜索收缩、连续 Tab／Shift+Tab，以及窄窗口滚动后的菜单定位，尚未全部人工验收。
3. **补复杂编辑与异常分支。** 账号向导的前后切换及校验；供应商和模型配置长表单；配图旧草稿冲突、位置修复、长描述和失败恢复；备份校验失败与恢复失败的界面；发布不同错误／重试分支。现有自动化已覆盖其中部分业务行为，仍需逐态视觉核对。
4. **用真实数据做桌面人工验收。** 长标题、多账号、多条数据、长错误、滚动到底部、Windows 125%／150% 缩放、不同窗口高度仍需补齐；真实供应商、公众号草稿箱及手机排版另行验证。
5. **按操作结果收敛提示。** 公共页头和重复说明已清理，但界面内仍有上下文帮助。继续判断能否由字段名、默认值、禁用条件或就近操作替代；保留实际错误、费用和不可逆操作所需信息。不要把删除所有文字当成验收标准。

本轮没有使用 Stitch 生成设计稿；已有产品视觉体系继续沿用。后续如调整整体布局，可先围绕明确的页面问题生成方案，再落地源码并以真实交互截图复核。
