# 公众号排版开源调研与视觉升级（2026-11-26）

## 1. 调研结论

当前开源公众号排版项目已经形成几类成熟做法：

1. **主题画廊 + 内容类型预设**：先按文章类型选一套完整版式，再微调颜色、字号、间距。
2. **微信安全区内联样式**：最终产物全部内联，避免依赖 `<style>`、媒体查询和伪元素。
3. **编辑部式视觉层级**：标题、正文、引用、图片、表格分别设计，而不是只换一个主题色。
4. **真实手机预览**：以 375px 左右的阅读宽度校准字号、行距与留白。
5. **外链脚注、图片图注、代码块等公众号专项处理**：兼顾美观与发布兼容性。

本次没有直接复制任何项目源码，而是参考其产品模式与视觉原则，结合现有渲染引擎重新设计主题。

## 3. 本次视觉升级

### 3.1 新增四套主题

- **编辑部**：杂志式层级、暖铜强调、舒适长文行距，适合观点、长文与品牌内容。
- **现代极简**：清晰蓝调、轻卡片标题、利落层级，适合教程、清单与专业内容。
- **森林 calm**：低饱和绿、柔和底色、宽松留白，适合品牌故事与深度阅读。
- **墨色书房**：宣纸暖底、墨棕强调、书卷气引用，适合人文、书评与叙事。

原「微信经典 / 杂志衬线 / 科技蓝 / 暖纸 / 极简黑白」继续保留，兼容已有排版稿与账号版式。

### 3.2 默认主题调整

- 默认主题从「微信经典」改为「编辑部」。
- 文章类型一键预设同步改为新版主题：
  - 教程 / 攻略 → 现代极简
  - 深度分析 → 编辑部
  - 专业 / 科技 → 现代极简
  - 叙事 / 随笔 → 编辑部
  - 清单 / 盘点 → 现代极简

### 3.3 主题选择方式升级

- 新增**可视化主题画廊**：直接查看主题缩略预览、名称与风格说明。
- 支持搜索主题。
- 保留原下拉选择，兼容熟练用户与窄屏场景。
- 主题卡片显示当前选中态。

### 3.4 排版细节优化

- 标题：明确字号、字重、行距与章节间距。
- 正文：提高行距与段落节奏，降低长文压迫感。
- 强调：主色只用于关键词、链接与锚点，不污染正文阅读。
- 引用：按主题区分左边线、卡片与纸面式引用。
- 图片：统一圆角、留白与图注层级。
- 表格：统一表头、边框、斑马纹与数值对齐。
- 组件：引言卡、金句卡、提示块、目录、章节编号与主题保持一致。

## 4. 微信兼容约束

本次新增主题继续遵守现有公众号安全区：

- 所有选择器作用于 `.mly-body` 或排版组件类。
- 最终样式通过 `juice` 内联。
- 不使用伪元素、媒体查询、动画、定位属性。
- 代码块继续使用微信兼容的 `section` 结构，不使用 `<pre>`。
- 外链继续转换为文末参考链接。
- 图片、表格、代码块均保留现有合规校验。

## 5. 验证

- 新增主题均加入 golden 基线，确保渲染产物稳定。
- 主题元信息、推荐逻辑与一键预设测试通过。
- 保留旧主题 golden 基线，确认兼容性。
- 后续需在真实公众号编辑器中做最终粘贴验收，自动化验证不能完全替代真机与平台行为。
