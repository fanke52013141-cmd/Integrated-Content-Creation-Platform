## 4. 发现的问题与优化建议

### P1：建议优先处理

#### 4.1 流程顺序与用户预期不一致

用户预期：`文章 → 排版 → 配图`。

应用当前主链路：`文章 → 评审（可选）→ 配图 → 排版`，并且“资料收集”不在顶部流水线中，只作为资源区存在。

实际影响：

- 用户先排版再插图时，应用会正确提示“此排版稿基于较早正文”，但必须再生成一次排版稿。
- “资料收集”在用户心智中是一个独立环节，但界面没有把它呈现为流程阶段。

建议：

- 在顶部流程中增加可选“资料”环节，或在框架完成后提供“去收集资料”的明确 CTA。
- 明确推荐顺序为“文章 → 配图 → 排版”；如果必须支持先排版，可在插图保存后提供“一键更新排版稿”。

#### 4.2 配图插入下拉的编号不稳定

实测正文插图下拉出现：

```text
发布图 1
文内图 2
文内图 3
```

原因是编号使用混合图片数组的位置，而不是按图片类型分别编号；生图完成顺序变化后，文内图可能从 2 或 3 开始，容易误选。

建议：

- 按 `cover / inline / release` 分组。
- 每类独立编号：`文内图 1`、`文内图 2`、`发布图 1`。
- 按 `kind + slot` 稳定排序，不使用数组完成顺序。

### P2：建议排入下一轮

#### 4.3 框架“深度预研”失败或未配置时被静默跳过

代码逻辑明确：未配置搜索模型或搜索失败时返回空上下文，不阻塞框架生成。

优点是稳，缺点是用户无法判断这次框架是否使用了联网资料。

建议：

- 在生成结果或框架卡片上显示：`已使用 X 条预研资料` / `预研未启用` / `预研失败，已跳过`。
- 失败时提供“重试预研”入口。

#### 4.4 直接进入框架页不会自动选中已锁定选题

从选题卡片的“生成框架→”进入时正常；但如果用户从侧栏直接进入“内容框架”，选题默认是“不关联选题”，需要手动选择。

建议：

- 存在当前锁定选题时，默认选中该选题。
- 保留“不关联选题”的手动覆盖能力。

#### 4.5 账号锁定后缺少下一步引导

账号保存并锁定后，用户需要自己回到侧栏寻找“热点洞察”或“选题生成”。

建议：

- 增加“下一步：找热点”和“直接生成选题”两个 CTA。

### P3：体验与性能优化

#### 4.6 热点页存在重复 CTA

收藏热点后，页面同时出现“去生成选题”和“生成选题”，语义重复。

建议：保留一个主按钮，另一个改为轻量文字链接或移除。

#### 4.7 热点刷新耗时与失败源提示

实测刷新全部约 39 秒，56 个平台中 9 个暂不可用。页面已有“暂不可用”数量，但用户还需要逐个平台排查。

建议：

- 提供“只重试失败平台”。
- 展示失败原因摘要，如 `微博需登录`、`快手需 Cookie`、`网络超时`。
- 对成功平台使用本地快照，避免每次进入都全量刷新。

#### 4.8 排版生成耗时较长

模拟服务环境下，两次排版生成均约 31–32 秒。虽然功能正确，但用户感知等待明显。

建议：

- 增加明确的分阶段进度（解析正文 → 渲染 → 合规校验 → 预览）。
- 对相同正文和主题缓存排版中间结果。
- 排查渲染测量是否为同步阻塞，必要时移到 Worker。

#### 4.9 供应商配置对新手仍有门槛

当前需要理解：接口地址、API Key、模型标识、模型类型（文本 / 搜索 / 生图）、默认模型。预设供应商已降低难度，但完整创作仍涉及多类服务。

建议：

- 增加“创作场景套餐”向导：文本模型 + 搜索模型 + 生图模型一次配置。
- 明确标注每类服务的用途、是否必需、计费方式。
- 对“只写作”用户提供最小配置路径。

## 5. 需要提前准备或确认的配置

### 必需

1. **文本模型**
   - 用于账号定位、选题、框架、文章、评审、配图方案。
   - 需要：OpenAI-compatible Base URL、API Key、Model ID。
   - 未配置时，选题 / 框架 / 文章生成按钮会禁用，并提示去配置。

### 强烈建议

2. **搜索模型**
   - 用于素材库联网搜索、框架深度预研。
   - 当前接入的是豆包搜索协议端点，不等同于普通对话模型。
   - 未配置时：素材库显示“搜索服务未配置”；框架仍可生成，但预研会静默跳过。

### 可选

3. **生图模型**
   - 用于 AI 配图。
   - 未配置时仍可“直接导入自己的图片”，正文插入和排版链路可用。

4. **微博 / 快手登录态**
   - 仅影响对应热点平台；其他平台和手动添加热点不受影响。

5. **公众号发布凭证**
   - 不属于本次八个环节，但后续发布需要 AppID / AppSecret。

### 需要确认的产品定义

- 当前“账号创建”指的是**内容账号定位**，不是系统用户注册 / 登录。应用是本地优先桌面应用，没有账号密码体系。
- 如果用户预期的是“注册平台账号”，需要另行确认是否要加入用户体系；如果指的是“建立内容账号”，当前流程已满足。
