# 心流 Desktop · 真机单号实战验收清单（批次 D 门禁）

> 在推进阶段三（一键生成流水线 + 矩阵多公众号）前，建议按本清单用真实模型、真实素材与真实公众号连续跑 3~7 天（每日 1~3 篇），验证每环真实体验与成本边界。

## 一、环境与服务连通性
- [ ] **主力文本供应商**（如 DeepSeek / 豆包 / Claude / Gemini 中转）：在「AI 服务」中点击「测试并加密保存」，状态显示「已验证」。
- [ ] **配图供应商**（API 或即梦 CLI）：生图端点连通，封面图（2.35:1）与正文图可正常落本地资产目录。
- [ ] **微信公众号通道**（可选，需实测发布时）：在「发布中心」填写 AppID / AppSecret，配置本机公网出口 IP 至微信公众平台白名单，点击「测试连接」通过。

## 二、逐环核心能力真机验收（对应批次 A / B / C）
- [ ] **账号记忆 + 标杆样文（批次 A）**：录入 1~3 篇真实代表作至「标杆样文」，打开 XML 预览确认字符预算正常；生成 1 篇框架与成稿，体感对比语感是否贴近本人风格且未照搬样文旧案例。
- [ ] **外部 Deep Research 资料接入（批次 C）**：
  - [ ] 从外部研究工具导出的 MD/DOCX/PDF 导入「素材库」；
  - [ ] 用「抓取网页正文」粘贴 1~2 篇公开文章或公众号链接入库，确认正文抽取干净。
- [ ] **框架对抗打磨 Skill（批次 C）**：开启「多轮对抗 Skill」生成框架，展开「Skill 多轮轨迹」检查挑刺与修订是否有效提升结构密度。
- [ ] **文章编辑器共创（批次 B & C）**：
  - [ ] 使用「即时体检」检查 AI 腔与空泛段落，点击问题可精准跳转定位；
  - [ ] 选中一段按 `Ctrl+K` 试用「选区 AI 改写」（如 `去 AI 味更自然`），对比 Diff 后局部应用；
  - [ ] 点击「标题与摘要」工坊，挑选 1 个标题一键替换 `# 一级标题` 并同步写入发布摘要。
- [ ] **公众号精排版自修 Skill（批次 C）**：开启「启用排版多轮自检自修 Skill」，检查渲染预览、暗色模式与复制粘贴到微信公众平台后台后的真实手机预览保真度（无溢出、无叠字、组件样式完整）。

## 三、成本与稳定性基线记录（批次 D）
在「数据与备份 → 模型用量与成本账本」中填写主力文本模型单价，连续观察后记录基线：
- 单篇完整流程（选题 → 框架 Skill → 成稿 + 局部改写 → 排版 Skill）平均 Token 消耗：约 `____` K Tokens
- 单篇估算文本成本：约 `¥____`；单篇配图成本：约 `$____`
- `extractBlock` / JSON 协议解析失败率：目标 `< 2%`（若某模型持续偏高，记录模型名并在提示词管理核对业务层）
- 每日至少执行 1 次「数据与备份 → 立即备份」，确认备份「检查」通过。
