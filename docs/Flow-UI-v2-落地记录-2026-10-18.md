## 三、第二轮：残留问题已全部清零（提交 `ab1fbc8`）

| 原问题 | 处理 |
|---|---|
| 选题生成 85px 吸底条盖住内容 | 吸底条改为静态（`topics.css`），并撤掉上一版加的 101px 预留——整卡随内容滚动 |
| AI 服务 说明文字被按钮压住 2 处 | 提交区 `position: sticky` → `static`（`providers.css`），操作按钮间距 10 → 8px |
| 提示词/素材库/选题 低对比度 | `--text-tertiary` 与 `--text-soft` 由 `#647084` → `#5b6474`（浅灰底 5.2:1）；选题页签选中角标 `#2563eb` → `#1d4ed8`（5.5:1） |

**关于"1.3:1"的更正**：上一版报告里提示词页 1.3:1、素材库 3.31:1 是**度量错误**——
我的亮度函数没有合成半透明背景，也把 `color(srgb 0.14 0.38 0.92 / 0.1)` 的 0–1 分量
当成了 0–255。真实值是 4.38:1 与 4.2–4.25:1，仍然低于 4.5 阈值，但没那么夸张。
现已修正度量函数（逐层 alpha 合成 + srgb 分量归一），并用它复验。
