1. **暗色 accent 兜底**：官方工具发现用户自选浅色 accent 在暗色下对比度不足——推送前会拦截提示，但更好的体验是主题层自动兜底（记入待办）。
2. **verify-render-check.mjs 与 `shared/render-measure.ts` 各持一份测量脚本**（TS 侧给 Electron、mjs 侧给 Chrome 验证），文件头有同步说明——改其一必须同步另一侧并重跑验证。
3. **官方 CLI 未进 CI**（Windows runner 的 puppeteer 下载不稳，方案审核时已决策）：作为本地/发布前工具使用。
4. golden 基线重新生成需显式 `MLY_REGEN_GOLDEN=1` 并附视觉说明（测试注释已写明）。
5. 小绿书推送未创建交付记录（图片消息无排版稿快照），结果以草稿 media_id 返回；如需纳入复盘统计，待「发表」能力上线后一并打通。
