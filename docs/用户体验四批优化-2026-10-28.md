# 用户体验四批优化记录

## 本地实现

- 首页独立读取作品、任务和待保存修改；失败时显示原因及重试，不将未知状态描述为没有数据。
- 生图续查区分供应商明确失败与结果暂不可确认；原任务可再次查询，不自动重复提交。已完成但本地资产缺失时进入待核对。
- 短列表支持键盘操作与焦点返回；账号切换支持键盘，错误提示采用高优先级读屏播报。
- 新工作区提供首次创作起点；下游页面解释工作草稿、保存版本和锁定状态，旧排版稿与当前正文不一致时提醒。
- 配图增加推荐设置和费用提示；交付页面按连接、准备、推送和后台发布展示步骤，按当前公众号和排版稿识别交付记录。
- 文章可选择基础可视化编辑。仅对能够安全往返的简单 Markdown 开放；表格、嵌套列表、代码块、原始 HTML 等继续使用源码编辑。输入产生不支持的嵌套结构时撤回该操作并提示，保留之前的正文。
- 连续输入合并待写草稿，保存和切换仍等待最新内容落盘。

## 验证

- `npm run build`：类型检查及构建通过。
- `npm test -- --maxWorkers=4`：36 个文件、356 项通过。
- `npm run test:ui-layout`：14 个页面、3 种窗口尺寸，以及首次引导、键盘选择和基础可视化编辑检查通过。浏览器使用演示数据。
- `MOLIU_SMOKE_BACKGROUND=1 node scripts/run-all-smokes.mjs`：16 套隔离 Electron 回归通过，外部响应使用模拟。之后增加了切换复杂文章时退出可视化编辑的小幅保护，并重新构建及运行页面回归。
- 真实新闻搜索返回 5 条结果并成功接入隔离素材库。现有文本服务返回 HTTP 429，供应商提示套餐已停用，真实文本生成未通过。

## 暂缓事项

按用户要求，真实付费生图、真实公众号草稿推送及手机端显示验收暂缓。模拟回归不代表这些真实服务已验收。后续需要启用可用文本及生图服务、选定测试公众号，再进行端到端验收。
